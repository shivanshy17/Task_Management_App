# Task_Management_App
This management app is just not another task management app with a boring UI or those old school operations. This is gonna be a management app which just doesn't help you manage stuff like how other apps did, it suggests better management tricks based on your previous record and also alerts when there is somemthing that goes out of management.
-> We will be adding a AI agent which will manage the tasks and will help in increasing the productivity of the user.
-> Task Management app shouls have a AI which can directly connect notion or google calendar so that it is convinient for the user to plan.
